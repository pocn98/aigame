# ASTRO BREAKER ☄️

우주를 탐험하며 소행성을 강화하고 행성을 파괴하는 브라우저 클리커 게임입니다.

## 플레이
- 게임 페이지를 열고 행성 또는 **소행성 발사** 버튼을 클릭하세요.
- 별가루를 모아 소행성 질량, 자동 채굴 드론, 충돌 추진 장치를 강화하세요.
- 행성을 파괴하면 보상을 받고 다음 행성으로 이동합니다.
- 진행 상황은 브라우저의 `localStorage`에 자동 저장됩니다.

## 실행
별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

## GitHub Pages 배포
저장소 Settings → Pages → Build and deployment에서 **Deploy from a branch**를 선택하고, Branch는 `main`, Folder는 `/ (root)`로 설정한 뒤 Save를 누르세요.

## 기술
- HTML / CSS / Vanilla JavaScript
- 외부 라이브러리 및 서버 불필요
