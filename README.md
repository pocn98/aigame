# 2040 — 숫자를 합쳐라

**2040**은 브라우저에서 바로 플레이할 수 있는 숫자 합치기 퍼즐 게임입니다.  
4×4 보드에서 같은 숫자 타일을 합쳐 더 큰 숫자를 만들고, 최고 기록에 도전해 보세요.

## 🎮 바로 플레이

👉 **[2040 게임 시작하기](https://pocn98.github.io/aigame/)**

별도 설치나 회원가입 없이 웹 브라우저에서 실행할 수 있습니다.

## 게임 방법

- 방향키 또는 **W / A / S / D** 키로 숫자 타일을 이동합니다.
- 모바일에서는 보드를 원하는 방향으로 밀어서 조작할 수 있습니다.
- 같은 숫자 타일 두 개가 만나면 하나로 합쳐지고 숫자가 두 배가 됩니다.
- 타일을 합칠 때마다 점수가 올라갑니다.
- 목표 숫자 **2048**을 만든 뒤에도 계속 플레이하며 더 높은 숫자에 도전할 수 있습니다.
- 더 이상 이동할 수 없으면 게임이 종료됩니다.

## 주요 기능

- 4×4 숫자 퍼즐 보드
- 키보드 및 모바일 스와이프 조작
- 현재 점수와 최고 점수 표시
- 브라우저에 최고 점수 자동 저장
- 한 번의 이동을 되돌리는 기능
- 새 게임 및 승리·게임 종료 안내
- 화면 크기에 맞춰 조정되는 반응형 디자인
