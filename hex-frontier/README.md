# HEX FRONTIER

브라우저에서 바로 실행하는 영역 점령 게임입니다.

## 실행
GitHub Pages가 켜져 있다면 `https://pocn98.github.io/aigame/hex-frontier/`에서 플레이할 수 있습니다. 로컬에서는 `index.html`을 열면 됩니다.

## 조작
- WASD 또는 방향키로 이동
- 내 영역 밖으로 나가 선을 그리고 내 땅으로 돌아오면 영역을 획득
- 선이 노출된 동안 상대와 부딪히지 않도록 주의

HTML, CSS, JavaScript만 사용하며 별도 설치나 서버가 필요하지 않습니다.
