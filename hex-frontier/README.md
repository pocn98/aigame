# HEX FRONTIER — Territory Wars

10명의 AI 라이벌과 넓은 전장에서 경쟁하는 브라우저용 영역 점령 게임입니다.

## 실행
GitHub Pages: https://pocn98.github.io/aigame/hex-frontier/

별도 설치나 서버 없이 `index.html`을 브라우저에서 열어도 실행할 수 있습니다.

## 규칙
- 내 영토뿐 아니라 상대 영토도 자유롭게 지나갈 수 있습니다.
- 영토 밖으로 나가면 이동 경로(꼬리)가 노출됩니다.
- 내 영토로 돌아오면 경로로 둘러싼 영역을 획득합니다.
- 상대의 노출된 경로에 닿으면 해당 경로만 끊깁니다. 공격한 플레이어가 죽거나 탈락하지 않습니다.
- 자기 경로에 다시 닿으면 진행 중인 경로가 취소됩니다.
- SPACE로 짧은 부스트를 사용할 수 있습니다.

## 조작
- 이동: WASD / 방향키
- 부스트: SPACE
- 일시정지: ESC 또는 일시정지 버튼
- 모바일: 화면 방향키

## 기술
HTML, CSS, Vanilla JavaScript, Canvas. 서버와 외부 라이브러리 없이 실행됩니다.
